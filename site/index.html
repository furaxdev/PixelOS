PixelOS

A custom Android distribution built on LineageOS — its own launcher, theming and system apps, aimed first at a Galaxy Tab 4 10.1 and an x86_64 build for VirtualBox/QEMU.

Source on GitHub Build it yourself

Why LineageOS-based

Maintained base

Kernel, HAL and drivers already ported per device — the same approach every vendor skin (ColorOS, OneUI, MIUI) actually uses.

We build the skin

Launcher, system UI, settings, theming, bundled apps — the layer that actually makes an Android distro feel like its own OS.

Security patches

Inherits upstream LineageOS CVE fixes instead of freezing on a single AOSP snapshot.
